# Pipecat — Overview

Source: https://docs.pipecat.ai/overview/introduction

**What it is** - Open source ecosystem (BSD-2) for building real-time voice and multimodal AI agents that can see, hear, and speak.

## Ecosystem

- **Pipecat Framework** - Open source Python framework that orchestrates 150+ AI services with ultra-low latency to build voice/multimodal pipelines.
- **Pipecat Clients** - Client SDKs for JavaScript, React, React Native, iOS, Android, and C++ to connect users to agents via web and mobile.
- **Pipecat Cloud & Enterprise** - Fully managed hosting in Daily-hosted regions, or agents running in your own VPC.

## Key Features

- **Provider-agnostic** - Works with any AI provider (STT, LLM, TTS, etc.); you only pay for the services you choose.
- **Real-time pipelines** - Server runs a pipeline that handles audio processing, LLM calls, and speech generation live.
- **Client-server model** - Clients (browser, mobile app, or phone) connect to a server that executes the agent pipeline.
- **Multimodal** - Supports voice, vision, and text in a single agent.
- **Deploy anywhere** - Run on Pipecat Cloud, your own VPC, or self-hosted infrastructure.
- **Enterprise support** - Maintained by Daily, with enterprise support for production deployments.

## Getting Started (recommended path)

1. **Quickstart** - Build and run a first agent.
2. **Learn Pipecat** - Core concepts (pipelines, frames, processors, services).
3. **Add a Client SDK** - Connect a web or mobile frontend.
4. **Deploy** - Pipecat Cloud or self-hosted.
